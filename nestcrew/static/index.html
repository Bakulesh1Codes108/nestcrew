Phone link — share files with your phone

Wi-Fi (fast): phone and PC on the same Wi-Fi. Press Start, scan the QR code with the phone's camera, and a page opens in its browser — no app to install. Send photos/videos/files to the PC (each one verified, then it tells you when they're safe to delete from the Gallery), and download what you put in Send to phone. Only devices on your network with the code can use it; it stops by itself after 30 idle minutes.

Bluetooth

Slower (about 1–2 MB/s) but needs no Wi-Fi. Opens Windows' own Bluetooth file transfer.

Automations

Recipes from automations.yaml plus Canvas workflows with a folder, time or interval trigger. They run while NestCrew is open. Unattended runs may only use tools listed as pre-approved — everything else is denied. "Run now" asks you in chat as usual.

Which model does which job

A capable "brain" runs chat and agents; tiny "eyes" models look at screens, video and documents. ★ marks the recommended model; hints explain each choice. Jobs use your default model until the chosen one is downloaded.
